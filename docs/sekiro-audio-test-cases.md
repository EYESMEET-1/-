# 《只狼：影逝二度》音频测试用例

被测对象：《只狼：影逝二度》

测试类型：音频功能、玩法表现、混音、空间定位、兼容性与性能黑盒测试

| 用例ID | 类型 | 优先级 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|---|
| SK-AUD-F01 | 功能 | P0 | 游戏已安装，音量未静音 | 从桌面启动游戏，进入主菜单 | 厂商Logo音、主菜单音乐和界面音效正常播放，无爆音、缺失或重复播放 |
| SK-AUD-F02 | 功能 | P1 | 已进入主菜单 | 依次执行上下选择、确认、返回和打开设置 | 每个菜单操作均有对应反馈音，快速连续操作时无音效堆积或明显延迟 |
| SK-AUD-F03 | 功能 | P1 | 已进入游戏并可自由移动 | 在草地、石地、木板、浅水和雪地分别移动 | 不同地面的脚步声材质特征可区分，步频与移动速度匹配，停止移动后无持续脚步声 |
| SK-AUD-F04 | 功能 | P0 | 已锁定或靠近敌人 | 使用普通攻击命中敌人，并分别在空挥、命中血肉和命中金属时观察 | 空挥、命中和被格挡音效可区分；命中音与攻击动画同步，无缺失和重复叠加 |
| SK-AUD-F05 | 功能 | P0 | 与敌人进入战斗 | 分别执行普通格挡、完美弹反和架势崩溃 | 三种反馈具有明确不同的声音层级；完美弹反具有清晰金属冲击与判定反馈，声音不早于或晚于画面判定 |
| SK-AUD-F06 | 功能 | P0 | 面对会使用危字攻击的敌人 | 分别触发突刺、下段和投技危字攻击，并在不同距离观察 | 危字出现时有明确提示音，提示音与危字UI同步；不同危险攻击若设计有差异，其声音可区分 |
| SK-AUD-F07 | 功能 | P0 | 敌人进入可忍杀状态 | 从正面和背后分别执行忍杀 | 忍杀触发音、处决音和结束反馈完整播放，与动作阶段同步；连续忍杀时无截断或串音 |
| SK-AUD-F08 | 功能 | P0 | 玩家已死亡且拥有回生能力 | 执行回生并继续战斗 | 回生启动、恢复和起身阶段的音效顺序正确；回生完成后战斗环境声和BGM恢复到正确状态 |
| SK-AUD-F09 | 功能 | P0 | 玩家生命被敌人清空 | 触发死亡并选择复活 | 死亡音效和复活流程音频完整；死亡音乐结束后不残留循环声部，复活后无旧状态音频叠加 |
| SK-AUD-F10 | 功能 | P1 | 玩家持有伤药葫芦 | 使用伤药葫芦，并在饮用、回复、取消或被打断时观察 | 使用动作与饮用音同步；成功回复和被打断具有不同结果；音效结束后不残留持续声 |
| SK-AUD-F11 | 功能 | P1 | 玩家装备义手忍具 | 分别使用手里剑、爆竹和机关斧 | 每种忍具具有可区分的释放、飞行、命中和结束音；重复使用后声部数量不会持续累积 |
| SK-AUD-F12 | 功能 | P1 | 附近存在钩绳点 | 从不同距离和方向执行钩绳移动 | 钩绳锁定、发射、连接和落地音效顺序正确；距离变化应影响音量或空间感；失败抓取有独立反馈 |
| SK-AUD-F13 | 功能 | P1 | 玩家处于潜行状态 | 从背后接近敌人并执行忍杀，同时制造噪音 | 潜行环境声持续稳定；忍杀和警报音不提前暴露玩家；敌人发现玩家后有明确的警报声和战斗状态切换 |
| SK-AUD-F14 | 功能 | P0 | 玩家进入敌人警戒范围 | 从探索状态进入战斗并脱离战斗 | 探索BGM平滑退出，战斗BGM正确进入；脱离警戒后恢复到对应探索音乐，无长时间静音、错曲或旧BGM叠加 |
| SK-AUD-F15 | 功能 | P0 | 进入多阶段Boss战 | 将Boss推进至下一阶段并完成击败 | 阶段切换时BGM按设计过渡，不出现爆音、断拍或错轨；Boss死亡后战斗BGM正确结束并进入胜利或环境状态 |
| SK-AUD-F16 | 功能 | P1 | 玩家处于可交互NPC附近 | 触发对话、跳过对话并结束交互 | 对话语音清晰，字幕与语音进度基本一致；语音期间BGM和环境声按设计压低，结束后恢复原音量 |
| SK-AUD-F17 | 功能 | P1 | 玩家处于剧情演出中 | 播放包含语音、音乐和环境声的剧情片段 | 三类声音均可识别，无对白被音乐遮蔽、无循环断点或演出结束后残留声音 |
| SK-AUD-F18 | 功能 | P1 | 游戏暂停菜单处于关闭状态 | 暂停游戏、调整音量、恢复游戏 | 暂停后音频进入正确状态；恢复后BGM从合理位置继续，不重置、不叠加、不出现明显断点 |
| SK-AUD-F19 | 功能 | P1 | 已修改音乐、音效和语音音量 | 退出菜单、切换场景并重新启动游戏 | 音量设置正确保存；各分轨调节互不串扰；将任一轨道调至最低时其他轨道仍正常 |
| SK-AUD-F20 | 功能 | P1 | 游戏正在播放BGM和战斗音效 | 使用系统静音或游戏静音功能 | 所有预期声部停止输出；取消静音后音量状态恢复，无一次性音效补播或循环声叠加 |
| SK-AUD-S01 | 空间 | P0 | 佩戴耳机并进入有多个敌人的区域 | 保持镜头朝向不变，让敌人在玩家左侧、右侧和正前方移动 | 脚步声和攻击声的声像方向与敌人相对位置一致，左右不反转，方向切换无跳变 |
| SK-AUD-S02 | 空间 | P1 | 佩戴耳机并处于立体声输出 | 让敌人在玩家上方、下方和不同高度位置移动 | 高度变化可通过音量、音色或空间感区分，不出现声音始终固定在屏幕中央 |
| SK-AUD-S03 | 空间 | P0 | 敌人在远处持续移动 | 让敌人从远距离靠近至近身，再远离 | 声音随距离平滑衰减和增强，不突然消失；近身时方向感和攻击反馈清晰 |
| SK-AUD-S04 | 空间 | P1 | 玩家可自由旋转镜头 | 保持敌人位置不变，旋转镜头并移动视角 | 世界空间音源方向保持正确，不因镜头旋转发生错误反转或声源漂移 |
| SK-AUD-M01 | 混音 | P0 | 进入高强度战斗 | 同时触发BGM、攻击、格挡、敌人语音和环境声 | 关键判定音不被音乐淹没；多声部叠加时无明显削波、爆音或声部消失 |
| SK-AUD-M02 | 混音 | P1 | 语音和BGM同时播放 | 触发NPC对话或Boss语音，并在播放中调整Music和Voice音量 | 语音期间BGM压低符合设计；调整分轨后立即生效；语音结束后BGM恢复原音量 |
| SK-AUD-M03 | 混音 | P1 | 玩家已完成音量校准 | 依次将Master、Music、SFX和Voice设置为0%、50%和100% | 每个滑块只影响对应总线；0%时对应声音完全静音；重新调整为正常值后无状态错乱 |
| SK-AUD-C01 | 兼容 | P0 | 准备扬声器和有线耳机 | 在两种输出设备下分别完成一场战斗 | 两种设备下均无声道缺失、电流声、明显延迟或音量异常；攻击和格挡反馈仍可辨认 |
| SK-AUD-C02 | 兼容 | P1 | 游戏运行中并连接蓝牙耳机 | 在游玩过程中切换至蓝牙输出，再切回原设备 | 声音可恢复到新输出设备；不崩溃、不持续静音、不出现双路播放或循环声叠加 |
| SK-AUD-C03 | 兼容 | P1 | 系统可切换采样率和音频格式 | 在关闭游戏后修改系统音频采样率，再重新启动游戏 | 游戏可正常输出音频；无变调、爆音、声道错位或启动失败 |
| SK-AUD-P01 | 性能 | P0 | 进入敌人数量较多的区域 | 连续攻击、格挡并触发多个敌人语音 | 音频保持连续；无卡顿、丢音、重复触发或活跃声部持续增长 |
| SK-AUD-P02 | 性能 | P1 | 面对可快速连续攻击的目标 | 连续快速攻击、弹反和切换忍具至少30秒 | 攻击与命中音效保持同步；设备资源占用无持续异常增长；停止操作后无残留声部 |
| SK-AUD-P03 | 性能 | P1 | 连续游玩多个区域 | 连续游玩并进行多次场景切换、Boss战和死亡复活 | BGM、环境声和音效持续稳定；长时间运行后无循环断点、声道漂移或音效延迟增加 |
| SK-AUD-R01 | 稳定性 | P1 | 游戏处于战斗状态 | 快速暂停、恢复、打开地图和返回游戏 | 音频状态与界面状态一致；恢复后无旧BGM叠加、音效补播或长时间静音 |
| SK-AUD-R02 | 稳定性 | P1 | 游戏处于加载或区域切换过程 | 在加载、区域切换和自动存档节点反复操作 | 加载音和过渡音正常播放；进入新区域后正确加载环境声和BGM，无旧区域声音残留 |
| SK-AUD-R03 | 稳定性 | P0 | 游戏窗口处于前台 | 将游戏切换至后台再返回，并触发一次战斗 | 后台时音频行为符合系统或游戏设计；返回后BGM、环境声和输入反馈恢复正常，无崩溃或持续静音 |
